## 🌟 ¿Qué es ÑUHU?
**ÑUHU** es una experiencia interactiva y videojuego experimental diseñado para explorar cómo la tecnología, la inteligencia artificial y los principios de ciberseguridad pueden unirse para acompañar a las personas en momentos de vulnerabilidad o sobrecarga digital, priorizando siempre la calma, la accesibilidad y la privacidad.

<br>

## 🛠️ Stack Tecnológico y Estructura
A diferencia de proyectos pesados con múltiples dependencias, este prototipo está optimizado como una **aplicación web de archivo único (Single-File App)** para garantizar un rendimiento inmediato y un despliegue ágil:

* **Frontend:** HTML5, CSS3 Moderno (Variables, Grid, Flexbox) y JavaScript Vanilla.
* **Interfaz Sensorial:** Integración de APIs nativas del navegador para el procesamiento local de video, audio y estímulos interactivos.
* **Hosting / Despliegue:** Desplegado de forma estática en **Vercel**.
